Install on Linux

Kali, Debian, Ubuntu, Mint, Raspberry Pi OS — apt installs everything it needs.
1
$ uname -m x86_64 → _amd64.deb aarch64 → _arm64.deb
Which CPU?x86_64 → amd64. aarch64 → arm64 (every Raspberry Pi 3/4/5 on 64-bit OS).
2
$ cd ~/Downloads $ sudo apt install ./sudosend_*_amd64.deb
Install the .debKeep the ./ in front of the file name — it tells apt this is a local file.
3
$ sudo ufw allow 47823/udp $ sudo ufw allow 47824:47833/tcp
Open the firewall (if you use one)SUDOSEND uses UDP 47823 for discovery and TCP 47824–47833 for transfers.
4
$ sudosend
or: curl -fsSL …/get.sh | bash
Start itFrom the applications menu, or type the command. Any other distro: tar.gz + ./install.sh
