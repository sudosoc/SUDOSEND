## What's new in 0.10.0

- **Share apps (Android)** — Send → **Apps**: pick installed apps (search, sort, include system apps) and send them like any file, encrypted and SHA-256 verified. Split Play Store apps travel as one set and install as one app.
- **Safe install** — open a received APK to see its name, package and version, whether it is new, an update, a downgrade or signed by a different developer, its permissions with sensitive ones highlighted, and the signer certificate fingerprint — then install (Android asks to confirm).
- Can be switched off in Settings → Features → Files.

## الجديد في 0.10.0

- **مشاركة التطبيقات (أندرويد)** — الإرسال ← **تطبيقات**: اختار التطبيقات المتسطبة (بحث، ترتيب، وتطبيقات النظام لو عايز) وابعتها زي أي ملف، مشفّرة ومتراجعة بالـ SHA-256. تطبيقات بلاي ستور المقسّمة بتتبعت كمجموعة وتتسطب كتطبيق واحد.
- **تسطيب آمن** — افتح الـ APK اللي وصلك تشوف اسمه والباكدج والنسخة، وهل هو جديد ولا تحديث ولا أقدم ولا موقّع من مطوّر تاني، وصلاحياته والحساسة متعلّم عليها، وبصمة شهادة التوقيع — وبعدين سطّب (أندرويد بيطلب تأكيد).
- تقدر تقفلها من الإعدادات ← المزايا ← الملفات.
