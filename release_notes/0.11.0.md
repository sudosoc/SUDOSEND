## What's new in 0.11.0 — a new look

- **New design language, "Obsidian"** — calm solid surfaces instead of frosted glass, one signal-green accent instead of a rainbow of gradients, no animated backdrop. Easier to read, lighter on the GPU, and it stays out of the way of your files.
- **Simpler structure** — four tabs instead of five: **Nearby** (send + receive in one place), **Files**, **Transfers**, **Messages**. The old Receive tab is now **My device**, one tap on the device chip at the top: QR, address, visibility.
- New typography (IBM Plex Sans + Plex Arabic + Plex Mono for fingerprints and addresses), labelled navigation, a slimmer composer, quieter section titles, themed switches/menus/chips.
- Chat: failed messages are re-sent when the device returns, day separators, offline hint; fixed a notify-during-build bug when opening a thread.
- Statistics: *Sent* and *Received* now use clearly different colours.
- README now has screenshots of every screen and an illustrated install guide.

## الجديد في 0.11.0 — شكل جديد

- **هوية بصرية جديدة "Obsidian"** — أسطح هادية صلبة بدل الزجاج، ولون مميز واحد (أخضر إشارة) بدل ألوان الـ gradient الكتير، وخلفية ثابتة. أوضح في القراءة وأخف على الجهاز.
- **هيكل أبسط** — أربع تابات بدل خمسة: **حواليك** (الإرسال والاستقبال في مكان واحد)، **الملفات**، **التحويلات**، **الرسايل**. تاب الاستقبال القديم بقى **جهازي**: دوس على كارت الجهاز فوق تلاقي الـ QR والعنوان والظهور.
- خطوط جديدة (IBM Plex)، وتابات بأسماء، وكارت اختيار الإرسال أصغر، وعناوين أهدى.
- الشات: الرسايل اللي فشلت بتتبعت تاني لما الجهاز يرجع، وفواصل أيام، وتنبيه لما الجهاز أوفلاين، وإصلاح باج عند فتح محادثة.
- الإحصائيات: المُرسَل والمُستلَم بقوا بلونين واضحين.
- الـ README فيه صور لكل الشاشات ودليل تثبيت مصوّر.
