## What's new in 0.8.0

- **In-app updates** — Settings → About → *Check for updates*. On Android the new APK downloads and opens the installer; on Windows the installer runs by itself; on Linux you get the one-line command. Every download is checked against GitHub's SHA-256.
- **Wi-Fi Direct (Android)** — link two phones directly with no router and no hotspot; both keep their normal Wi-Fi and data. Receive → *Wi-Fi Direct*.
- **Smart file organization** — received files are filed automatically into `SUDOSEND/<device>/<type>/<date>/` (Documents, Pictures, Videos, Audio, Archives, Applications, Code, Other Files); sent folders stay whole. Each level can be switched off.
- **Per-device permissions** — choose for each trusted device what it may do (auto-accept, messages, clipboard, ring, sync, speed test) and give it its own folder name.
- **Photo privacy** — GPS location is stripped from JPEG/PNG photos before sending (or all metadata, or none), without re-compressing. Originals can be allowed per device.
- **Files tab** — every received file in one place: search by name, extension, device, date, size and type; list or **timeline** by day; **in-app preview** of photos, videos, audio, PDFs, text and code.
- **Duplicate detection** — SHA-256 spots files identical to ones you already have, even under another name; keep both or drop the new copy, and clean duplicates in one tap.
- **Devices** — profiles with system, first/last seen, connection history and transfer history; nicknames, groups (Personal, Work, your own) and *send to group*; auto-reconnect to known devices even where broadcast is blocked.
- **Permission profiles** — per device: both ways / receive only / send only, trust that expires (1 h – 30 days), per-device archiving rules.
- **Audit log** — connections refused, requests, transfers, trust changes, deletions, risky files; export CSV or JSON Lines for a SIEM.
- **Secure file handling** — warnings before opening programs, scripts, macro files and disguised files (`invoice.pdf.exe`, executables renamed to .pdf); received files carry Windows Mark-of-the-Web / macOS quarantine.
- **Storage** — free-space monitoring, warnings, automatic refusal of transfers that would not fit, usage by device and type.
- **Statistics** — totals, average and top speed, activity by day/week/month, top senders, types, duplicates; reports as CSV, JSON or PDF.
- **Drag & drop onto a device** (desktop) sends straight to it; notifications can be chosen per type.
- **Developer page** under Settings → About.
- Optional automatic update check at startup (Settings → Features → App), off with one switch.

## الجديد في 0.8.0

- **تحديث من جوه التطبيق** — الإعدادات ← عن التطبيق ← *دوّر على تحديث*. على أندرويد الـ APK بيتحمّل والمثبّت بيفتح، على ويندوز المثبّت بيشتغل لوحده، وعلى لينكس بياخد أمر التثبيت. كل تحميل بيتراجع بالـ SHA-256.
- **واي فاي دايركت (أندرويد)** — وصّل موبايلين ببعض على طول من غير راوتر ولا هوتسبوت، والاتنين بيفضلوا على الواي فاي والداتا بتاعتهم. الاستقبال ← *واي فاي دايركت*.
- **ترتيب ذكي للملفات** — كل ملف بيوصل بيتحط لوحده في `SUDOSEND/<الجهاز>/<النوع>/<التاريخ>/`، والفولدرات اللي بتتبعت بتفضل زي ما هي. تقدر تقفل أي مستوى.
- **صلاحيات لكل جهاز** — تحدد كل جهاز موثوق يقدر يعمل إيه (قبول تلقائي، رسايل، حافظة، رنّة، مزامنة، اختبار سرعة) وتدّيله اسم فولدر خاص.
- **خصوصية الصور** — موقع الـ GPS بيتشال من صور JPEG وPNG قبل الإرسال (أو كل البيانات، أو ولا حاجة) من غير ما الصورة تتضغط تاني. وتقدر تسمح بالأصل لأجهزة معيّنة.
- **تبويب الملفات** — كل الملفات المستلمة في مكان واحد: بحث بالاسم والامتداد والجهاز والتاريخ والحجم والنوع؛ قايمة أو **خط زمني** باليوم؛ **معاينة جوه التطبيق** للصور والفيديو والصوت والـ PDF والنصوص والأكواد.
- **اكتشاف المكرر** — الـ SHA-256 بيلاقي الملفات المطابقة للي عندك حتى لو باسم تاني؛ سيب الاتنين أو امسح الجديد، ونضّف المكرر بدوسة.
- **الأجهزة** — ملف تعريفي فيه النظام وأول وآخر ظهور وسجل الاتصال وسجل النقل؛ أسماء مستعارة ومجموعات (شخصي، شغل، أو اللي تعمله) و*ابعت للمجموعة*؛ وإعادة اتصال تلقائي بالأجهزة المعروفة حتى لو البرودكاست مقفول.
- **ملفات الصلاحيات** — لكل جهاز: الاتجاهين / استقبال بس / إرسال بس، ثقة بتنتهي (ساعة – 30 يوم)، وقواعد أرشفة خاصة.
- **سجل المراجعة** — الاتصالات المرفوضة، الطلبات، النقل، تغييرات الثقة، المسح، الملفات الخطرة؛ تصدير CSV أو JSON Lines لـ SIEM.
- **تعامل آمن مع الملفات** — تحذير قبل فتح البرامج والسكريبتات وملفات الماكرو والملفات المتنكرة (`invoice.pdf.exe`)؛ والملفات المستلمة بتتعلّم Mark-of-the-Web على ويندوز وquarantine على ماك.
- **التخزين** — مراقبة المساحة وتحذيرات ورفض تلقائي للنقل اللي مش هيكفّي، واستهلاك حسب الجهاز والنوع.
- **الإحصائيات** — إجماليات، متوسط وأعلى سرعة، النشاط باليوم/الأسبوع/الشهر، أكتر المرسلين، الأنواع، المكرر؛ تقارير CSV أو JSON أو PDF.
- **اسحب وأفلت على جهاز** (كمبيوتر) يتبعتله على طول، والإشعارات تقدر تختار أنواعها.
- **صفحة المطوّر** في الإعدادات ← عن التطبيق.
- فحص تلقائي للتحديثات أول ما التطبيق يفتح (الإعدادات ← المزايا ← التطبيق) وتقدر تقفله.
